# TheDeadlies | 赎罪之旅

一个适用于 Minecraft 1.20.1 的赎罪之旅桌游插件。玩家通过聊天栏中的可点击组件出牌、选择目标并处理卡牌效果。

**English version: [README_EN.md](README_EN.md)**

## 环境与安装

- 服务端：Paper / Purpur 1.20.1
- Java：17
- 将 `build/libs/TheDeadlies-1.0.0-all.jar` 放入服务端的 `plugins` 文件夹，然后重启服务器。

首次启动后，在 `plugins/TheDeadlies/config.yml` 中设置界面语言，并重启服务器生效：

```yaml
language: ZH_CN # 可选：ZH_CN（默认）或 EN
```

从源码构建：

```text
gradlew.bat shadowJar
```

## 指令

| 指令 | 用途 |
| --- | --- |
| `/thedeadlies invite <玩家> [玩家...]` | 邀请一名或多名在线玩家；所有受邀玩家都需要处理邀请 |
| `/thedeadlies joingame <房主>` | 向房主申请加入尚未开始的房间 |
| `/thedeadlies quitgame` | 退出房间或当前对局；对局中房主退出会结束并解散房间 |
| `/thedeadlies startgame` | 房主开始游戏，至少需要两名在线玩家 |
| `/thedeadlies endgame` | 结束本局但保留房间，之后可以重新开始 |

同意或拒绝邀请、同意或拒绝加入申请，以及出牌和效果响应，均可点击聊天栏组件完成。回合中必须打出至少一张牌，不能主动跳过。

## 游戏规则

- 游戏共 52 张牌：净化 1 张、腐化 1 张、七种罪恶牌各 7 张、光环 1 张。光环单独公开放置，其余 51 张组成牌堆。
- 每位玩家初始获得 6 张牌，罪恶值为 6。
- 每回合打出一张或多张牌。多张牌必须满足同数字、同牌名或至少三张连续数字顺子之一；结算数字最大的一张牌。最大数字并列时，选择其中一张结算。
- 手牌打空时，罪恶值减 2，并重新抽取等同于当前罪恶值的牌。罪恶值降至 0，或第三次打空手牌时获胜。
- 牌堆抽空后，将弃牌洗回牌堆；光环不进入牌堆。

## 卡牌效果

| 牌 | 效果 |
| --- | --- |
| 傲慢 | 询问另一名玩家是否展示傲慢；展示则你抽 1 张，否则对方抽 1 张。 |
| 嫉妒 | 抽 2 张牌；若手中没有嫉妒，可以与一名玩家交换手牌。 |
| 愤怒 | 选择另一名玩家，对方抽 2 张；然后双方轮流选择弃掉愤怒继续，或停止循环。 |
| 懒惰 | 放在自己面前；面前有懒惰的对手抽 1 张。该牌在你下回合开始时弃置。 |
| 贪婪 | 选择其他玩家逐张发牌。发出两张非贪婪牌且最后一张不是贪婪时，可以停止；两张同牌名牌会强制停止并收回发出的牌。发出 5 张后可以清空手牌。 |
| 暴食 | 选择从另一名玩家手中随机抽 1 张，或自己抽 3 张；然后获得额外回合。 |
| 色欲 | 选择另一名玩家。对方可以不做任何事，或双方各弃 1 张牌；弃掉色欲的一方使另一方抽 3 张。 |
| 净化（0） | 将光环拿入手牌，即使光环当前在其他玩家手中。 |
| 腐化（8） | 打出时选择七种罪恶牌之一，并执行对应效果。 |
| 光环 | 清空自己的手牌；打出或弃掉后，将光环正面朝上放回桌面中央。 |

> 罪恶值最高为 6；规则允许使用最高为 4 的变体玩法。

## 操作提示

游戏开始后，自己的手牌会以可点击卡牌显示。点击卡牌即可出牌；需要目标、腐化花色或牌效响应时，按提示点击相应选项。鼠标悬停在卡牌上可查看牌效。
